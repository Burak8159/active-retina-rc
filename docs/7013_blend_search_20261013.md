# 70.13 Reference: Bounded Candidate Search

## Result

The frozen pooled reference remains unchanged at **270/385 = 70.13%**, with zero observed referable or ungradable misses on its repeatedly inspected 981-case cohort.

A post-hoc per-source rank blend of the existing component scores replays at **272/385 = 70.65%** on those same 981 cases: two additional gradable negatives cleared, with zero observed misses on that cohort. The recipe and operating thresholds were selected using these same labels. It is therefore an exposed-cohort diagnostic, not an independently validated improvement or a deployable model. Its reproducible script and outputs are `src/active_retina/audit_7013_blended_candidate.py` and `results/deployable_exposed_baseline_7065_20261013/`.

## Stress Checks

- Using the blend weights with patient-grouped fold-specific score references and thresholds yielded **272/385** negatives cleared but **4 held-out positive misses** (1 DDR, 1 DeepDRiD, 2 DRTiD). Lowering the pooled out-of-fold threshold until no observed OOF positives were cleared produced **268/385 = 69.61%**; weights had still been selected after this cohort was inspected.
- Learned source-specific selectors on the available model-score library did not recover the target. Best tested patient-grouped OOF zero-miss specificity was **45.19%** for a shallow extra-trees selector; logistic regression was **39.74%**. These are development diagnostics, not independent validation.
- The casewise oracle audit identifies up to **23** additional negatives that some individually thresholded model score would clear. That uses each case’s known label to choose a helpful score and is not an inference policy.

## Decision

No current model or score policy has demonstrated a generalizable result above the frozen 70.13% reference, and none has reached 75% with zero misses. The 70.65% same-cohort replay is retained only as a clearly labeled exploratory candidate. Do not change the frozen reference, clinical station, or deployment profile from this result. A meaningful next improvement needs a selector trained on genuinely separate calibration predictions and tested on a new patient-disjoint cohort, or a materially new model/data signal.
