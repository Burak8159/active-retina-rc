# DRTiD Access Request Note

Subject: DRTiD dataset access request

Dear DRTiD team,

I am requesting access to the DRTiD dataset for an academic, noncommercial
research project on risk-controlled paired-view retinal imaging for diabetic
retinopathy screening.

The project studies whether a frozen computational model can safely use
macula-centered and optic-disc-centered fundus images to support referable
diabetic retinopathy triage while reducing unnecessary image acquisition and
deferring uncertain cases for clinician review. DRTiD is directly relevant
because it contains paired two-field fundus images with DR grading labels.

I will use the dataset only for research, will not redistribute the data, and
will cite the DRTiD / CrossFiT paper and repository according to your
requirements. If there are any additional conditions, documents, or identity
information needed, I would be happy to provide them.

Thank you for making this dataset available to researchers.

Best regards,
Burak Aksu
