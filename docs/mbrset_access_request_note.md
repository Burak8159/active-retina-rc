# mBRSET Access Request Note

Subject: mBRSET access for noncommercial diabetic retinopathy screening research

Dear mBRSET / PhysioNet team,

I am requesting access to mBRSET for an academic, noncommercial research project
on risk-controlled retinal image acquisition for diabetic retinopathy screening.
The project studies whether paired portable-camera fundus views can support
safe referable diabetic retinopathy triage while reducing unnecessary image
acquisition.

The planned use is limited to reproducible research and model validation. I will
not redistribute the data, will keep the data within the approved research
environment, and will cite the mBRSET dataset, the associated publication, and
PhysioNet according to the stated requirements.

The specific validation goal is to evaluate a frozen computational model on an
untouched mBRSET cohort, with no threshold tuning after access. The main endpoint
is referable diabetic retinopathy using ICDR grade >= 2. The analysis requires
patient identifiers, laterality, image filenames, image-quality labels, ICDR
labels, and the retinal images.

Thank you for making this dataset available to researchers.

Best regards,
Burak Aksu
