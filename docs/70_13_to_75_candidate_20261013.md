# 70.13-to-75 Candidate Update (2026-10-13)

## Frozen reference

The reference is unchanged at **270/385 = 70.13%** on its repeatedly inspected 981-case cohort, with zero observed referable or ungradable misses and 100% action coverage. It remains a development-only reference, not independent clinical validation.

## Expanded fine-tune

- Initialized from the MMRDR-UWF ResNet-50 checkpoint.
- Fine-tuned all parameters at 448 px on 11,971 training images from DDR, DeepDRiD, DRTiD, and IDRiD; the development validation split contained 1,338 images from 982 eyes.
- Audit correction: the manifest did **not** keep the 981-eye reference cohort separate from model selection. All 981 reference eyes occur in its `source_split=valid` rows (1,337 image rows across 982 eyes); `original_source_split` retains prior `*_test`/`*_valid` labels. Thus epoch and threshold selection used the same exposed cases as the 70.13 reference. The earlier claim that prior validation/test paths were excluded was incorrect.
- Best epoch was 3. Its zero-miss operating point on the training script's 982-eye validation split was 95/386 gradable negatives (**24.61%**); epochs 4 and 5 regressed to 54 and 55 true negatives.
- The saved epoch-3 checkpoint was scored on the exact 981-eye reference cohort. The best tested ordinal score form with source-specific thresholds yielded 119/385 standalone true negatives. This overlapped heavily with the frozen reference.
- A post-hoc source-specific threshold search on the frozen reference produced **275/385 = 71.43%**, zero observed misses on that same exposed cohort, and five additional true negatives. A pooled threshold produced 274/385 = 71.17%. Because this cohort was also used for model/threshold selection, neither number is evidence of a new generalizing model gain.

## Interpretation and next experiment

This is a **same-cohort, post-hoc diagnostic**, not a validated or deployable improvement: the 981 reference eyes are in the candidate's validation split, and risk/quality cutoffs were also selected from those labels. The base model adds only five cases beyond the frozen actions, showing that its errors are highly correlated with the reference. It is 14 additional true negatives short of the arithmetic 75% target (289/385).

The planned source-and-patient-balanced continuation was subsequently run on the RTX; its results and split audit are recorded below. Do not promote 71.43% as a frozen model result; preserve 70.13% as the original baseline.

## Balanced-sampling run update

The RTX became reachable and the source-and-patient-balanced continuation was run using the same 448-pixel MMRDR-initialized ResNet-50, all 23.5M parameters trainable, and the existing development-only train/validation manifest. The sampler assigned equal total sampling mass to DDR, DRTiD, DeepDRiD, and IDRiD, then equal mass to patients within each source. The manifest contains 8,219 DDR, 2,166 DRTiD, 1,180 DeepDRiD, and 406 IDRiD training images; the collected summary's hard-coded dataset description omitted IDRiD, so the manifest is the source of truth for composition.

The run's raw summary, progress history, and validation predictions are preserved in `results/combined_mmrdr_qualitygate_balanced_allft_20261013/`. The balanced run used the same exposed 981 reference eyes for validation-based selection. Its best checkpoint was epoch 0; trained epochs 1-3 all regressed. Reaching 75% on the exposed reference denominator requires 289 true negatives, so the source-specific post-hoc comparison remains 14 cases short. That arithmetic gap is not a promise that those cases can safely be cleared; the existing casewise oracle relies on labels and is not an implementable policy. No new 75% result was achieved.

## Corrective gate

Before another candidate is selected, construct a patient-disjoint development split that excludes every eye in the frozen 981-case reference from both training and model/threshold selection, and audit the split by both `eye_id` and `patient_id`. The old reference may be used only as a clearly labeled exposed diagnostic; it cannot serve as the untouched certification set. A claim of independent 80/0/100 or 90/0/100 still requires a genuinely untouched cohort.
